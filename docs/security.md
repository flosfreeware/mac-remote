# Mac Remote security

- No accounts, ads, analytics, or developer-operated relay servers.
- Remote commands go directly between your paired iPhone and Mac over an authenticated, encrypted connection.
- Pairing codes expire; only a paired iPhone can send remote-control commands.
- Accessibility access is used to move the pointer and simulate key presses when you use the remote.
- Diagnostics are saved locally on your Mac and are not uploaded by Mac Remote.
- Update checks contact GitHub. GitHub may receive ordinary connection metadata, but update checks do not include pairing credentials or remote-control activity.
- Unpairing removes the Mac’s saved pairing credential. You can also reset Mac Remote’s local settings and pairing data.
